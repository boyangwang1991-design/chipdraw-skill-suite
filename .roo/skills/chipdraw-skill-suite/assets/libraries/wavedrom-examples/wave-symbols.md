# WaveDrom wave 字符速查表

每个字符代表一个时间周期（`wave` 字符串）。`data` 数组的每个元素对应一个 **非 `.`** 周期（按顺序）。

## 电平字符

| 字符 | 含义 |
|---|---|
| `0` | 低电平 |
| `1` | 高电平 |
| `x` | 未知 / 高阻（可配 data 值，表示总线数据"无效"） |
| `z` | 高阻（三态） |
| `=` | 延续前一状态（同 `0` 延续逻辑） |
| `-` | 无变化（延续前一状态） |
| `.` | **延续前一状态一个周期**（不产生独立 data 位） |
| `|` | Spacer / Gap 分隔符（不占时间周期，仅视觉分隔） |
| `+` | 与下一周期同时刻（Sharp 线箭头同拍标记） |

## 时钟字符

| 字符 | 含义 |
|---|---|
| `p` | 正极性时钟，**无**边沿标记（上升沿每周期） |
| `P` | 正极性时钟，**带**边沿标记 |
| `n` | 负极性时钟，**无**边沿标记 |
| `N` | 负极性时钟，**带**边沿标记 |
| `h` | 高电平保持半拍（用于与时钟混合做门控） |
| `l` | 低电平保持半拍 |
| `H` / `L` | 高/低电平，带边沿标记 |

> 时钟字符可与普通电平混合，产生 **时钟门控（Clock Gating）** 效果，例如 `phnlPHNL`。

## 数据字符

| 字符 | 含义 |
|---|---|
| `2`-`9` | 多位数据总线显示（引用 `data` 数组对应元素） |
| `=` | 数据延续（总线值保持，仍可配 data） |

## 总线 data 匹配规则

- `data` 数组长度 = `wave` 中 **非 `.` 周期** 的数量（`|` 不算周期，`+` 与相邻周期同拍）。
- 示例：`wave: "x.==.=x", data: ["head","body","tail","data"]` → 4 个非 `.` 周期匹配 4 个 data 元素。
- `data` 内可嵌入 HTML/JsonML 样式的 `<o>...</o>`（上标）等。

## node（箭头锚点）

- `node` 字符串与 `wave` 同长，每个字符代表一个周期；`a-z`/`A-Z` 为锚点名，`.` 为空。
- 配合顶层 `edge` 数组定义箭头：`'a->b label'`、`'a~b'`、`'a-|b'` 等。

## edge（箭头）连接符

| 组合 | 含义 |
|---|---|
| `~` | Spline（曲线） |
| `-` | 直线 |
| `\|` | 直角折线 |
| `>` | 箭头（指向终点） |
| `<` | 反向箭头 |
| `+` | 同拍（竖直短线） |

示例：`'a~b t1'`（spline 无箭头）、`'c-~>d time 3'`（直线+曲线+箭头）、`'g<->h 3 ms'`（双向）。
`config.arcFontSize` 可调箭头弧线标签字号。

## 顶层 gaps（Gap 表达式）

定义 lane 之间的 Spacer 尺寸与 Gap 位置（用于在波形中插入间隔，模拟总线空闲/延迟）。

| 记号 | 含义 |
|---|---|
| `.` | 默认 Spacer |
| `s` | 小 Spacer |
| `S` | 大 Spacer |
| `1`-`9` | Gap 编号（在该位置断开时间轴） |
| `( ... )` | 分组（作用于一组 lane） |
| `|` | 显式 Spacer 分隔 |

示例：`'1.1s.1'`、`'(. |.. )'`、`'. s'`、`'(.. 1. s. 1 s.. 1 s. s. )'`。

## over / under（建立/保持时间窗口）

lane 属性，`over` 与 `under` 为与 wave 同长的字符串，在信号上下方绘制
建立/保持时间窗（常用于时序收敛注释、CDC 检查）：

```yaml
- {name: dat ->, wave: "x...3...", data: ["D"],
   over: "0.....10", under: "0.1....."}
```

## path 波形（模拟/自定义形状）

`wave` 可为数组 `['pw', {d: 'SVG path 命令'}]`，用 SVG path 绘制任意模拟/自定义波形
（正弦、锯齿、三角、RC 充放电、PLL 锁定曲线等）：

```yaml
- {name: sin, wave: ["pw", {d: "m,0,.5 q,.25,1,.5,0 t,.5,0,.5,0"}]}
```

常用 path 命令：`m/M`(move) `l/L`(line) `q/Q`(quadratic) `t/T`(smooth) `v/V`(vertical) `h/H`(horizontal)。

## 寄存器位域图（reg）

顶层 `reg` 为位域数组，`bf` 渲染寄存器图；`config` 控制 hspace/vspace/lanes/compact/hflip/vflip 等：

```yaml
reg:
  - {name: opcode, bits: 7, attr: "OP-IMM"}
  - {name: rd, bits: 5, attr: "dest"}
  - {name: imm[11:0], bits: 12, attr: "I-immediate[11:0]", type: 3}
config: {hspace: 600, lanes: 2}
```
